Python 3 Dunder (Double-Underscore) Methods & Attributes

Commonly used Python 3 dunders grouped by purpose across the data model:

Object Creation, Lifecycle & Representation

  • __new__(cls, ...) — Allocates and returns a new instance before __init__ runs.
  • __init__(self, ...) — Initializes a newly created instance.
  • __del__(self) — Finalizer called when an instance is about to be destroyed (garbage collected).
  • __str__(self) — Human-readable string conversion used by str(obj) and print(obj).
  • __repr__(self) — Unambiguous/debugging string representation used by repr(obj) and interactive shells.
  • __format__(self, format_spec) — Custom formatting hook used by format(obj, spec) and f-strings (f"{obj:spec}").
  • __bytes__(self) — Byte string conversion used by bytes(obj).
  • __hash__(self) — Returns an integer hash so instances can be dict keys or set elements.
  • __bool__(self) — Truth-value testing used by bool(obj) and if obj: (falls back to __len__ if absent).

Rich Comparison Operators

  • __eq__(self, other) — Equality (==)
  • __ne__(self, other) — Inequality (!=)
  • __lt__(self, other) — Less than (<)
  • __le__(self, other) — Less than or equal (<=)
  • __gt__(self, other) — Greater than (>)
  • __ge__(self, other) — Greater than or equal (>=)

Attribute Access & Descriptors

  • __getattr__(self, name) — Called only when normal attribute lookup (__getattribute__ + __dict__ + MRO) fails.
  • __getattribute__(self, name) — Intercepts every attribute access on an instance.
  • __setattr__(self, name, value) — Intercepts every attribute assignment (obj.attr = val).
  • __delattr__(self, name) — Intercepts attribute deletion (del obj.attr).
  • __dir__(self) — Customizes attributes returned by dir(obj).
  • __get__(self, instance, owner) — Descriptor getter (data or non-data descriptor).
  • __set__(self, instance, value) — Data descriptor setter.
  • __delete__(self, instance) — Data descriptor deleter.
  • __set_name__(self, owner, name) — Called on descriptors when assigned to a class body attribute.

Callable, Containers, Sequences & Mappings

  • __call__(self, *args, **kwargs) — Allows an instance to be called like a function (obj()).
  • __len__(self) — Returns item count for len(obj).
  • __getitem__(self, key) — Subscript/indexing lookup (obj[key]).
  • __setitem__(self, key, value) — Subscript assignment (obj[key] = value).
  • __delitem__(self, key) — Subscript deletion (del obj[key]).
  • __contains__(self, item) — Membership testing (item in obj).
  • __iter__(self) — Returns an iterator object for iter(obj) / for loops.
  • __next__(self) — Returns the next item from an iterator or raises StopIteration.
  • __reversed__(self) — Custom reverse iteration for reversed(obj).
  • __missing__(self, key) — Called by dict.__getitem__ when a key is not found.

Numeric, Bitwise & In-Place Operators

  • Binary arithmetic: __add__, __sub__, __mul__, __matmul__ (@), __truediv__ (/), __floordiv__ (//), __mod__ (%), __divmod__, __pow__ (**).
  • Reflected (right-hand) arithmetic: __radd__, __rsub__, __rmul__, __rmatmul__, __rtruediv__, __rfloordiv__, __rmod__, __rdivmod__, __rpow__.
  • In-place augmented assignment: __iadd__ (+=), __isub__ (-=), __imul__ (*=), __imatmul__ (@=), __itruediv__ (/=), __ifloordiv__ (//=), __imod__ (%=), __ipow__ (**=).
  • Unary arithmetic & conversions: __pos__ (+x), __neg__ (-x), __invert__ (~x), __abs__, __round__, __trunc__, __floor__, __ceil__, __index__.
  • Bitwise & reflected/in-place bitwise: __and__, __xor__, __or__, __lshift__ (<<), __rshift__ (>>) along with their r (__rand__, etc.) and i (__iand__, etc.) counterparts.

Context Managers, Coroutines & Class/Module Metadata

  • __enter__(self) / __exit__(self, exc_type, exc_val, exc_tb) — Synchronous context manager protocol (with statement).
  • __aenter__(self) / __aexit__(self, exc_type, exc_val, exc_tb) — Asynchronous context manager protocol (async with).
  • __aiter__(self) / __anext__(self) — Asynchronous iterator protocol (async for).
  • __await__(self) — Makes an object awaitable (await obj).
  • Common special attributes: __dict__, __class__, __bases__, __mro__, __name__, __qualname__, __module__, __doc__, __annotations__, __slots__, __init_subclass__, __class_getitem__.
