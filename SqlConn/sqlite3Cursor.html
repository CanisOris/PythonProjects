Python 3 sqlite3.Cursor Methods and Attributes

Core methods and attributes on a Python 3 sqlite3.Cursor object for executing SQL, retrieving rows, and inspecting query state:

Executing SQL Statements

  • execute(sql[, parameters]) — Executes a single SQL statement using ? (qmark) or :name (named) parameter binding.
  • executemany(sql, seq_of_parameters) — Executes a parameterized SQL command (INSERT, UPDATE, DELETE) repeatedly across an iterable of parameter tuples/mappings.
  • executescript(sql_script) — Executes multiple semicolon-separated SQL statements at once (implicitly commits any open transaction first in standard sqlite3 usage).

Fetching Results

  • fetchone() — Returns the next row of a query result set as a single tuple (or configured row factory object), or None when no more rows remain.
  • fetchmany([size=cursor.arraysize]) — Returns the next batch of up to size rows as a list (returns an empty list [] when no rows remain).
  • fetchall() — Returns all remaining rows of a query result set as a list (returns an empty list [] if no rows match).

Iteration & Cleanup

  • __iter__() / __next__() — Lets you iterate directly over the cursor (for row in cursor:) to stream rows one at a time.
  • close() — Closes the cursor and releases its resources.

Useful Attributes After Execution

  • rowcount — Number of rows affected by the last INSERT, UPDATE, or DELETE (or -1 if unknown/not applicable).
  • lastrowid — Row ID (rowid) of the last inserted row on a DML statement against a rowid table (otherwise None).
  • description — Sequence of 7-tuples describing each result column (name, type_code, display_size, internal_size, precision, scale, null_ok), or None for statements that don't return rows.
  • arraysize — Default number of rows returned by fetchmany() (defaults to 1).
  • connection — Reference back to the sqlite3.Connection object that created the cursor.
  • row_factory — Per-cursor callable used to shape returned rows (overrides or complements Connection.row_factory).
