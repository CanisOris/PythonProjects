Python 3 I/O Commands and io Module Reference

In Python 3, input/output spans the built-in open() function and the standard library io module for files, text/binary streams, and in-memory buffers.

Built-In File & Console I/O

  • open(file, mode='r', buffering=-1, encoding=None, errors=None, newline=None, closefd=True, opener=None) — Opens a file or stream and returns a file object (TextIOWrapper, BufferedReader, BufferedWriter, BufferedRandom, or RawIOBase subclass depending on mode and buffering).
  • input([prompt]) — Reads a line from standard input (sys.stdin), strips a trailing newline, and returns it as a str.
  • print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False) — Writes formatted representations of objects to file (defaulting to standard output).

Common File Object Methods

  • read(size=-1) — Reads up to size characters (text mode) or bytes (binary mode), or until EOF if size is omitted or negative.
  • readline(size=-1) — Reads a single line up to \n or size characters/bytes.
  • readlines(hint=-1) — Reads remaining lines and returns them as a list of strings/bytes.
  • write(s) — Writes a str (text mode) or bytes-like object (binary mode) to the stream and returns the number of characters/bytes written.
  • writelines(lines) — Writes an iterable of strings or bytes-like objects to the stream (does not add line separators automatically).
  • seek(offset, whence=os.SEEK_SET) — Moves the stream position (0 / SEEK_SET from start, 1 / SEEK_CUR from current position, 2 / SEEK_END from end).
  • tell() — Returns the current stream position (an opaque number in text mode; byte offset in binary/buffered mode).
  • flush() — Flushes write buffers to the underlying OS/stream.
  • close() — Flushes and closes the stream (handled automatically on exit when using with open(...) as f:).

io Module Classes & Buffers

  • io.StringIO(initial_value='', newline='\n') — In-memory text stream using a string buffer (implements text I/O methods like read(), write(), getvalue()).
