For extracting structured entities and relationships from unstructured text to populate a node/graph database, the current Python ecosystem relies heavily on LLM-driven orchestration alongside traditional NLP pipelines.

LLM Orchestration Frameworks

LangChain: Provides a Neo4jGraph integration and LLMGraphTransformer (or OpenAI functions via get_extraction_chain) to pass text through an LLM, extract nodes and relationships as Pydantic models, and load them directly into a graph.

LlamaIndex: Utilizes PropertyGraphIndex and tools like the SchemaLLMPathExtractor to manage the end-to-end creation of knowledge graphs from unstructured data.

Neo4j GraphRAG Package: Features a SimpleKGPipeline class that takes a Neo4j driver, an LLM for entity extraction, and an embedding model to automatically chunk text, extract entities, and build the graph locally or on AuraDB.

Dedicated Text-to-Graph Extraction Libraries

Graph Maker (knowledge-graph-maker): Highly optimized for local, open-source models like Llama 3 or Mixtral. You define your graph's ontology strictly using Pydantic models, and it chunks the corpus, extracts nodes/edges, and allows direct saving to Neo4j.

KGGen: An open-source package that extracts triples from text and features a built-in LLM-driven clustering pipeline to automatically merge synonymous nodes (e.g., "vulnerabilities" and "weaknesses") before they hit the database.

eknowledge: A lightweight PyPI package dedicated to leveraging language models to parse unstructured text and export structured relationships.

NLP & Hybrid Extractors

spaCy: For non-LLM, deterministic extraction, spaCy plugins handle coreference resolution and dependency parsing to extract entities and their grammatical relations, which can then be mapped to database queries.

GLiNER & SciPhi Triplex: Specialized small models for Named Entity Recognition and knowledge graph extraction that integrate with LangChain and graph databases to extract relationships without relying on massive, generalized LLMs.
