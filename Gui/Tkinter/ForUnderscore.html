Python: for _, variable

Tuple unpacking with a throwaway variable convention

Overview

In Python, for _, variable in ... is a for loop using tuple unpacking where _ is a naming convention for an ignored (throwaway) variable, and variable captures the value you want to use.

It commonly appears when iterating over sequences of pairs or tuples—such as enumerate() or dict.items()—where only one element of each pair is needed.

Common Examples

1. With enumerate() (ignoring the index)

enumerate() yields (index, item) pairs. Use _ when you only need the item:

fruits = ["apple", "banana", "cherry"]

for _, fruit in enumerate(fruits):
    print(fruit)
# Output:
# apple
# banana
# cherry

2. With dict.items() (ignoring the key)

dict.items() yields (key, value) pairs. Use _ when you only need the value:

prices = {"apple": 1.20, "banana": 0.50, "cherry": 3.00}

for _, price in prices.items():
    print(price)
# Output:
# 1.2
# 0.5
# 3.0

3. With a list of tuples

Unpack the tuple elements directly and ignore the first value:

coordinates = [(10, 20), (30, 40), (50, 60)]

for _, y in coordinates:
    print(y)
# Output:
# 20
# 40
# 60

Important Notes

  • _ is a regular variable name: Python does not treat _ as special loop syntax. Each iteration assigns the first tuple element to _; using _ simply signals to readers that the value is intentionally unused.
  • Watch for name collisions and direct methods: In a REPL, _ holds the last evaluated expression, and tools like gettext also bind _. When you don't need a dictionary key at all, for price in prices.values(): is often clearer than unpacking and ignoring the key.
