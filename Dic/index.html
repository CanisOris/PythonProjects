Python 3 Dictionary (dict) Instructions & Reference

In Python 3, a dict (dictionary) is a mutable mapping that stores key: value pairs with fast average-case O(1) lookup, insertion, and deletion. Since Python 3.7+, dictionaries preserve insertion order.

1. Creating Dictionaries

# Literal syntax with key: value pairs
profile = {
    "name": "Alice",
    "role": "Analyst",
    "active": True,
}

# Empty dictionary
empty_dict = {}

# dict() constructor (keyword args, list of 2-tuples, or zip)
from_kwargs = dict(host="localhost", port=5432)
from_pairs = dict([("a.txt", 120), ("b.txt", 340)])
zipped = dict(zip(["id", "name"], [1, "notes.txt"]))

# Dictionary comprehension
ext_counts = {ext: 0 for ext in [".txt", ".csv", ".py"]}

2. Reading & Safe Lookup

print(profile["name"])          # "Alice" (raises KeyError if key is missing)
print(profile.get("email"))     # None (returns default instead of KeyError)
print(profile.get("email", "")) # "" (custom fallback value)

# Membership test checks keys (not values)
if "role" in profile:
    print(profile["role"])

3. Adding, Updating & Removing Entries

# Add or overwrite a value
profile["email"] = "alice@example.com"
profile["role"] = "Senior Analyst"

# Merge / update multiple keys at once (or use `dict1 | dict2` in Python 3.9+)
profile.update({"role": "Lead Analyst", "team": "Core"})
merged = profile | {"env": "dev"}

# Set default only if key is not already present
tags = {}
tags.setdefault("txt", []).append("readme.txt")

# Remove entries
removed_val = profile.pop("team", None)  # Removes key & returns value (or None if absent)
last_key, last_val = profile.popitem()    # Removes and returns last inserted (key, value)
del profile["email"]                      # Deletes key (raises KeyError if missing)
# profile.clear()                         # Removes all items in place

4. Iterating Over Keys, Values & Items

scores = {"a.txt": 10, "b.txt": 25}

for key in scores:                   # Iterates over keys (same as scores.keys())
    print(key)

for val in scores.values():          # Iterates over values
    print(val)

for key, val in scores.items():      # Iterates over (key, value) tuples
    print(f"{key}: {val}")

5. Key Rules & Gotchas

  • Keys must be hashable: Strings, numbers, and tuples of hashable items (("tbl_files", "ID")) work as keys; lists, dicts, and sets raise TypeError: unhashable type because they are mutable.
  • Assignment copies a reference, not a clone: alias = scores points to the same dictionary; use scores.copy() for a shallow copy.
  • Avoid mutating a dict while iterating over it: Collect keys to remove into a list first rather than deleting keys during for k in d:.
