Terms and Commands Used

A quick reference to the concepts and commands covered on this page.

Key terms

Arithmetic operator
Performs numeric calculations such as addition or division.
Comparison operator
Compares values using operations such as equality or ordering.
Logical operator
Combines truth tests or negates them; and and or can return an operand value.
Assignment operator
Binds a value to a target or updates it with an augmented assignment.
Identity operator
Checks whether references identify the same object.
Membership operator
Tests whether a value belongs to a collection; dictionaries test keys.
Bitwise operator
Operates on the bits of integer values.

Key commands

+ / - / *
Add, subtract, or multiply numbers; + and * also support sequence concatenation and repetition.
/ / // / % / **
True division, floor division, remainder, and exponentiation.
== / !=
Test value equality or inequality.
and / or / not
Combine truth tests with short-circuit evaluation or negate a truth value.
is / in
Test object identity or membership in a collection.
& / | / ^ / ~
Integer bitwise AND, OR, exclusive OR, and inversion.
<< / >>
Shift an integer's bits left or right.
