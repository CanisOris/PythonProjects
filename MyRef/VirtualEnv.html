Python Virtual Environment Commands

← Back to index

Here are the standard commands for creating, starting up (activating), shutting down (deactivating), and managing a Python virtualenv (or venv) environment. Commands vary slightly between Linux/macOS and Windows.

Setup and Start Up (Activation)

  • Create an environment: 
    python -m venv venv

    Or use virtualenv venv if using the standalone virtualenv package.

  • Activate on Linux / macOS (bash / zsh): 
    source venv/bin/activate
  • Activate on Linux / macOS (fish shell): 
    source venv/bin/activate.fish
  • Activate on Windows (Command Prompt): 
    venv\Scripts\activate.bat
  • Activate on Windows (PowerShell): 
    venv\Scripts\Activate.ps1

Shut Down (Deactivation) and Removal

  • Deactivate (exit the environment) on any OS or shell: 
    deactivate
  • Delete an environment completely: Deactivate first, then remove the environment directory: 
    rm -rf venv          # Linux / macOS
rmdir /s /q venv    # Windows CMD

Package and Environment Management

  • Check which Python executable is active: 
    which python    # Linux / macOS
where python    # Windows
  • List installed packages: 
    pip list
  • Install a package: 
    pip install requests
  • Export exact dependencies to a file: 
    pip freeze > requirements.txt
  • Install dependencies from a requirements file: 
    pip install -r requirements.txt
  • Upgrade pip inside the environment: 
    python -m pip install --upgrade pip

Troubleshooting Quick Check

  • PowerShell script execution blocked on Windows: If Activate.ps1 throws an execution policy error, run: 
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  • Wrong Python version used: Specify the interpreter explicitly when creating the environment: 
    python3.12 -m venv venv    # Linux / macOS
py -3.12 -m venv venv      # Windows

Terms and Commands Used

A quick reference to the concepts and commands covered on this page.

Key terms

Virtual environment
An isolated Python environment with its own installed packages.
venv
Python's standard-library module for creating virtual environments.
virtualenv
A separately installed tool for creating virtual environments.
Activation
Updating the current shell's environment so the virtual environment's commands take precedence.
Deactivation
Restoring the shell environment that was active before activation.
Package / Dependency
Installable Python software, or software required by a project.
requirements.txt
A file listing package requirements that pip can install.
Interpreter
The Python executable that runs code.
PATH
The environment variable listing directories searched for commands.

Key commands

python -m venv venv
Creates a virtual environment in the directory named venv.
virtualenv venv
Creates an environment using the separately installed virtualenv tool.
source venv/bin/activate
Activates the environment in bash or zsh.
source venv/bin/activate.fish
Activates the environment in the fish shell.
venv\Scripts\activate.bat
Activates the environment in Windows Command Prompt.
.\venv\Scripts\Activate.ps1
Activates the environment in Windows PowerShell.
deactivate
Restores the shell state from before activation without deleting the environment.
which python / where python
Locate Python in Unix-like shells or Windows Command Prompt; in PowerShell use where.exe python or Get-Command python.
pip list
Lists installed packages in the environment associated with pip.
pip install requests
Installs the requests package.
pip freeze > requirements.txt
Writes installed package specifications to a requirements file.
pip install -r requirements.txt
Installs packages specified by a requirements file.
python -m pip install --upgrade pip
Upgrades pip for the selected Python interpreter.
Set-ExecutionPolicy
Configures PowerShell script execution policy; the example on this page changes the current user's policy.
python3.12 -m venv venv / py -3.12 -m venv venv
Selects Python 3.12 when creating the environment.
rm -rf venv / rmdir /s /q venv
Deletes the named environment directory in a Unix-like shell or Windows Command Prompt; this is separate from deactivation.
