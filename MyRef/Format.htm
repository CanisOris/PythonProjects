Python format() Manual

← Back to index

A reference guide covering single-argument string coercion and two-argument format specification mini-language usage.

1. Single-Argument Usage: format(value)

When passed a single argument, format() acts as a wrapper around the object's string representation (similar to calling str(obj) or invoking __format__("")).

# Converts objects/booleans directly to their string form
is_equal = format(5 == 5)
print(is_equal)  # Output: "True"

2. Two-Argument Usage: format(value, format_spec)

When passed a second argument, it invokes the Format Specification Mini-Language. This is identical to the engine used inside f-strings (e.g., f"{value:spec}").

# Binary conversion with 8-bit zero padding
binary_str = format(13, "08b")
print(binary_str)  # Output: "00001101"

3. Format Specification Reference Mini-Language

Specifier Type / Description Example Output
b Binary integer format(60, "b") 111100
08b Binary, zero-padded to 8 bits format(13, "08b") 00001101
x / X Hexadecimal (lowercase / uppercase) format(255, "x") ff
o Octal format(60, "o") 74
.2f Floating point with 2 decimal places format(3.14159, ".2f") 3.14
>10 Right-aligned within 10 spaces format("test", ">10")       test

Terms and Commands Used

A quick reference to the concepts and commands covered on this page.

Key terms

String formatting
Converting values into text using presentation rules.
Format specification
A string controlling type, field width, alignment, padding, or precision.
Binary / Octal / Hexadecimal
Base-two, base-eight, and base-sixteen number representations.
Precision
A formatting control whose meaning depends on the type; fixed-point precision specifies digits after the decimal point.
Alignment / Zero padding
Positioning a value inside a field or filling a numeric field with leading zeros.

Key commands

format()
Formats a value using its optional format-specification string.
str()
Returns a string representation of an object.
__format__()
Defines how an object responds to format() and formatted string fields.
f-string
A string literal prefixed with f that evaluates expressions inside braces and supports format specifications.
b / o / x / X
Integer presentation types for binary, octal, and lower- or uppercase hexadecimal.
f / > / 0
Fixed-point presentation, right alignment, and numeric zero padding within a format specification.
