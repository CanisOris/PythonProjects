Python 3 Function-to-Function Passing Variations

← Back to index

In Python 3, passing data or behavior from one function to another—or chaining functions together—takes several distinct forms depending on whether you are passing values, functions themselves, or mutable state.

1. Direct Return-to-Argument Passing (Chaining / Composition)

One function computes a value and returns it to a caller, which passes that result directly as an argument to another function.

def clean_filename(raw_name):
    return raw_name.strip().lower()


def has_txt_extension(name):
    return name.endswith(".txt")


result = has_txt_extension(clean_filename("  Notes.TXT  "))

2. Passing Functions as Arguments (Higher-Order Functions & Callbacks)

Functions are first-class objects in Python, so you can pass a function reference (without ()) into another function to be invoked inside it.

def apply_check(value, predicate_fn):
    return predicate_fn(value)


is_text = apply_check("readme.txt", lambda s: s.endswith(".txt"))

3. Passing Anonymous Functions (lambda)

A short, single-expression function defined inline at the call site and passed directly into another function (common with sorted(), map(), filter(), or custom callbacks).

names = ["b.txt", "a.txt", "c.txt"]
sorted_names = sorted(names, key=lambda item: item[0])

4. Passing *args and **kwargs (Argument Forwarding / Wrapper Functions)

A wrapper or intermediary function accepts arbitrary positional (*args) and/or keyword (**kwargs) arguments and forwards them along to another function.

def log_and_run(fn, *args, **kwargs):
    print(f"Calling {fn.__name__}")
    return fn(*args, **kwargs)


output = log_and_run(max, [10, 45, 22], default=0)

5. Partial Application (functools.partial)

Pre-fills some arguments of an existing function to create a new callable with fewer required arguments, then passes or calls it elsewhere.

from functools import partial


def ends_with_ext(filename, ext):
    return filename.endswith(ext)


is_txt = partial(ends_with_ext, ext=".txt")
print(is_txt("todo.txt"))  # True

6. Passing Mutable Objects (Shared In-Place Mutation)

Passing a mutable structure (such as a list, dict, or custom class instance) from one function to another allows the receiving function to mutate the object's contents in place (while reassigning the local parameter name inside the callee does not rebind the caller's variable).

def collect_txt_files(source_names, target_list):
    for name in source_names:
        if name.endswith(".txt"):
            target_list.append(name)


matches = []
collect_txt_files(["a.txt", "b.py", "c.txt"], matches)

7. Returning a Function from a Function (Closures & Factory Functions)

One function defines and returns an inner function that "remembers" variables from the enclosing function's scope (a closure), which can then be called or passed to other functions.

def make_suffix_checker(suffix):
    def checker(text):
        return text.endswith(suffix)
    return checker


check_txt = make_suffix_checker(".txt")
print(check_txt("notes.txt"))  # True

8. Generator / Iterator Handoff (yield and yield from)

One generator function yields items or delegates a sub-generator to another function/consumer so data streams lazily from stage to stage without building full intermediate lists.

def txt_only(filenames):
    for name in filenames:
        if name.endswith(".txt"):
            yield name


def formatted_lines(filenames):
    for fname in txt_only(filenames):
        yield f"TXT FILE: {fname}"

Terms and Commands Used

A quick reference to the concepts and commands covered on this page.

Key terms

Function composition
Passing the result of one function as an argument to another.
Callback / Higher-order function
A callback is supplied to other code to call; a higher-order function accepts or returns functions.
Closure
A function retaining access to variables from an enclosing function scope.
Partial application
Creating a callable with some arguments already supplied.
Mutable state
Data that can be changed in place and shared between functions.
Generator
An iterator that produces values as requested rather than building an entire sequence at once.

Key commands

def / return
Define a function and finish a call with an optional result.
lambda
Creates a small anonymous function containing a single expression.
*args / **kwargs
Collect additional positional and keyword arguments in a definition, or unpack them in a call.
functools.partial()
Creates a callable with selected arguments already supplied.
yield / yield from
Yield values from a generator or delegate iteration to another iterable.
