# PythonProjects

A repository for Python coursework and practice projects from The Tech Academy.

## Getting started

Install Git and Python 3, then clone the repository:

```sh
git clone https://github.com/CanisOris/PythonProjects.git
cd PythonProjects
```

## Projects

There are no Python scripts in the repository yet. Once a standalone script is added, run it from the repository root with `python path/to/script.py`, replacing the path with the script's actual location.
